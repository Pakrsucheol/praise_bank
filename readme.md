✨ 우리반 칭찬 통장 (Praise Bank)

학교 현장에서 학생들의 긍정적인 행동을 격려하고 기록하기 위한 웹 기반 칭찬 기록 애플리케이션입니다. 별도의 서버 설치 없이 브라우저의 로컬 저장소(LocalStorage)를 사용하여 간편하게 칭찬 데이터를 관리할 수 있습니다.

!

🚀 주요 기능

학생 명단 관리: 우리 반 학생들의 명단을 자유롭게 추가하고 삭제할 수 있습니다.

칭찬 기록 시스템: 선생님 성함, 날짜, 칭찬 내용을 입력하여 학생별로 칭찬을 기록합니다.

실시간 통계: 오늘 받은 칭찬 횟수와 이번 달 누적 기록을 한눈에 확인할 수 있습니다.

검색 및 필터링: 기록된 칭찬 내용을 키워드로 빠르게 검색할 수 있습니다.

데이터 유지: 브라우저를 닫아도 LocalStorage를 통해 데이터가 안전하게 저장됩니다.

반응형 디자인: PC, 태블릿, 모바일 기기 어디서든 최적화된 화면으로 접속 가능합니다.

🛠 사용된 기술

Frontend: React (v18), Tailwind CSS

Icons: Lucide Icons

Fonts: Pretendard

Storage: Browser LocalStorage

💻 설치 및 실행 방법

이 프로젝트는 별도의 빌드 과정이 필요 없는 단일 HTML 파일로 구성되어 있습니다.

이 저장소를 클론(Clone)하거나 index.html 파일을 다운로드합니다.

브라우저(Chrome, Edge, Safari 등)에서 index.html 파일을 엽니다.

또는 GitHub Pages를 설정하여 온라인 주소로 접속할 수 있습니다.

📝 사용 팁

개인 기기 사용 권장: 데이터가 브라우저에 저장되므로, 가급적 선생님의 전용 노트북이나 태블릿으로 사용하시는 것이 좋습니다.

아이콘 커스텀: Icon 컴포넌트의 name 속성을 Lucide Icons에서 찾아 변경할 수 있습니다.

선생님의 따뜻한 한마디가 아이들의 미래를 바꿉니다. 😊
